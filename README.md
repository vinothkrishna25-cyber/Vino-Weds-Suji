# Vino Weds Suji - Wedding Website

A beautiful and elegant wedding website celebrating the union of Vino (Krishnan Family) and Suji (Sankar Family).

## 🌟 Features

- **Welcome Page**: An elegant welcome page introducing the Krishnan and Sankar family function
- **Open Button**: Navigate from the welcome page to the main website with a smooth transition
- **Home Page**: Overview of the couple and family connection
- **Events Schedule**: Details of all wedding events and celebrations
- **Photo Gallery**: Showcase of memorable moments (ready to be populated with images)
- **About Section**: Beautiful story of the couple and family values
- **Contact Page**: Easy way for guests to reach out with questions

## 📁 Project Structure

```
├── index.html          # Welcome page (landing page)
├── main.html          # Home page after clicking OPEN
├── events.html        # Events and schedule
├── gallery.html       # Photo gallery

├── contact.html       # Contact and feedback form

```

## 🚀 How to Use

1. **Clone or Download** the repository
2. **Open `index.html`** in your web browser to see the welcome page
3. **Click the "OPEN" button** to navigate to the main website
4. **Explore** the different pages using the navigation menu

## 🎨 Customization

### Update Event Details
- Edit `events.html` to add your actual dates, times, and venues

### Add Photos to Gallery
- Replace the emoji placeholders in `gallery.html` with actual image URLs

### Update Contact Information
- Edit `contact.html` to add your phone number, email, and address

### Personalize Colors
Edit the color variables in `styles.css`:
```css
:root {
    --primary-color: #d4a574;      /* Gold */
    --secondary-color: #8b4513;    /* Brown */
    --accent-color: #c41e3a;       /* Red */
    --text-dark: #333333;
    --text-light: #f5f5f5;
    --bg-light: #faf8f3;
}
```
